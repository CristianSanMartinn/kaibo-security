# Imágenes actuales del Hero

El carrusel utiliza únicamente estos tres archivos:

- `hero-supermercado.png`: imagen ilustrativa entregada por el usuario.
- `hero-guardias-metro-santiago-v3.png`: escena generada con IA, inspirada en el Metro de Santiago. No documenta un evento real ni acredita una relación comercial con Metro.
- `hero-3-original.jpg`: fotografía entregada por el usuario.

Orden, encuadre y tiempo de rotación: `src/features/landing/data/hero.ts`, objeto `heroMedia`.

Las imágenes antiguas y variantes descartadas se eliminaron de esta carpeta por solicitud del usuario.
